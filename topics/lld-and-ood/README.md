# Low-Level Design & Object-Oriented Design

18 topics. Study content and MCQs live in per-topic
subfolders. See the master taxonomy in `../../TOPICS.md`.

The machine-coding / LLD interview round: design extensible, maintainable OO systems in
45-90 minutes. This domain teaches the **design method** (requirements → objects → APIs →
patterns → extensibility), the OOP and SOLID foundations that justify every design choice,
and a library of canonical LLD problems that interviewers draw from. Each problem topic
walks through the full design — from requirements clarification to class diagram to code
skeleton — so learners see the *process*, not just the answer.

Boundaries: design-patterns (dp-*) owns the **taxonomy** of patterns (GoF, enterprise,
concurrency); THIS domain shows when and how to APPLY them in a live design session.
dsa-coding owns data-structure internals and algorithmic problems. system-design owns
high-level distributed architecture.
